# Add custom DNS server on Android

Adding custom DNS server on Android works out of the box for each
connected Wi-Fi network separately. There is no need to install external
Apps.


## Change DNS server in Android directly

1.  Navigate to **Settings -\> Wi-Fi**

2.  **Press and hold** on the Wi-Fi network you want to change

3.  Choose **Modify network**

    <figure>
    <img src="/_includes/figures/dns-server/android/android-wifi-list.jpg"
    width="250" alt="Android: Wi-Fi list" />
    <figcaption aria-hidden="true">Android: Wi-Fi list</figcaption>
    </figure>

4.  Scroll down and click on **Advanced options**

    <figure>
    <img
    src="/_includes/figures/dns-server/android/android-wifi-advanced-options.jpg"
    width="250" alt="Android: Advanced options" />
    <figcaption aria-hidden="true">Android: Advanced options</figcaption>
    </figure>

5.  Scroll down and click on **DHCP**

    <figure>
    <img
    src="/_includes/figures/dns-server/android/android-wifi-select-dhcp-options.jpg"
    width="250" alt="Android: Select DHCP options" />
    <figcaption aria-hidden="true">Android: Select DHCP options</figcaption>
    </figure>

6.  Click on **Static**

    <figure>
    <img
    src="/_includes/figures/dns-server/android/android-wifi-select-dhcp-options-static.jpg"
    width="250" alt="Android: Select static DHCP options" />
    <figcaption aria-hidden="true">Android: Select static DHCP
    options</figcaption>
    </figure>

7.  Scroll down and change the DNS server IP for **DNS 1** (the first
    DNS server in the list)

    <figure>
    <img
    src="/_includes/figures/dns-server/android/android-wifi-set-dns-server.jpg"
    width="250" alt="Android: Add custom DNS server" />
    <figcaption aria-hidden="true">Android: Add custom DNS
    server</figcaption>
    </figure>

## Change DNS server with Third-Party App

If the above does not work for you or you just want another App that
makes it even easier to change DNS settings, you can search the
Playstore for many available DNS changer Apps. They also work on
non-rooted Androids.
