# Add custom DNS server on iPhone

Adding custom DNS server on iPhone works out of the box for each
connected Wi-Fi network separately. There is no need to install external
Apps.


## Change DNS server in iPhone directly

1.  Navigate to **Settings -\> Wi-Fi**

2.  Tap on your active Wi-Fi connection

    <figure>
    <img src="/_includes/figures/dns-server/iphone/iphone-wifi-list.jpg"
    width="250" alt="iPhone: Wi-Fi list" />
    <figcaption aria-hidden="true">iPhone: Wi-Fi list</figcaption>
    </figure>

3.  Scroll down and tap on **Configure DNS**

    <figure>
    <img src="/_includes/figures/dns-server/iphone/iphone-wifi-settings.jpg"
    width="250" alt="iPhone: Wi-Fi list" />
    <figcaption aria-hidden="true">iPhone: Wi-Fi list</figcaption>
    </figure>

4.  Select **Manual**

    <figure>
    <img
    src="/_includes/figures/dns-server/iphone/iphone-wifi-select-manual.jpg"
    width="250" alt="iPhone: Wi-Fi list" />
    <figcaption aria-hidden="true">iPhone: Wi-Fi list</figcaption>
    </figure>

5.  Add your DNS server IP (ensure it is the first in the list)

    <figure>
    <img
    src="/_includes/figures/dns-server/iphone/iphone-wifi-set-dns-server.jpg"
    width="250" alt="iPhone: Wi-Fi list" />
    <figcaption aria-hidden="true">iPhone: Wi-Fi list</figcaption>
    </figure>

## Change DNS server with Third-Party App

If the above does not work for you or you just want another App that
makes it even easier to change DNS settings, you can search the AppStore
for many available DNS changer Apps. They also work on non-rooted
iPhones.

<div class="seealso">

`app iphone dns override`
