# Add custom DNS server on MacOS


## Assumption

This tutorial is using `127.0.0.1` as the DNS server IP address, as it
is the method to setup Auto DNS for your local Devilbox.

## Network preferences

1.  Open System Preferences
2.  Go to **Network**
3.  Select your **active** connected interface
4.  Click on **DNS** tab
5.  Add new DNS server by clicking the **+** sign
6.  Add `127.0.0.1` as the first entry
