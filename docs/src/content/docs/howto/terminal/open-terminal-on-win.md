## Docker for Windows

Docker for Windows (the native Docker implementation) does not have any
special requirements for initial environment variable setup. Simply open
either

- Command Prompt
- PowerShell

> [!IMPORTANT]
> Do not open **PowerShell ISE**

<div class="seealso">

`install docker win`

</div>

## Docker Toolbox

1.  On your Desktop, find the Docker QuickStart Terminal icon.

<figure>
<img
src="/_includes/figures/terminal/docker-toolbox-terminal-win-quickstart-shortcut.png"
alt="Copyright docs.docker.com" />
<figcaption aria-hidden="true">Copyright docs.docker.com</figcaption>
</figure>

2.  Click the Docker QuickStart icon to launch a pre-configured Docker
    Toolbox terminal.

    If the system displays a **User Account Control** prompt to allow
    VirtualBox to make changes to your computer. Choose **Yes**.

<figure>
<img
src="/_includes/figures/terminal/docker-toolbox-terminal-win-quickstart-terminal.png"
alt="Copyright docs.docker.com" />
<figcaption aria-hidden="true">Copyright docs.docker.com</figcaption>
</figure>

> The terminal runs a special bash environment instead of the standard
> Windows command prompt. The bash environment is required by Docker.

You can now use this terminal window to apply all your Docker and
Devilbox related commands.
